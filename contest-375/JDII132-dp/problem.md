# JDII132 线性DP·编辑之距

- 比赛：集训队试炼02 线性DP
- 题型：OI
- 难度：Mid
- 语言：C, C++, Java, Python3

## 题目描述

<p>藏剑阁的书架上，赵晴儿发现了两卷残缺的剑谱——剑谱 A 长 N 字符，剑谱 B 长 M 字符。守阁长老言道：两卷剑谱虽非同一版本，但其中隐藏着共同的武学精髓——即最长公共子序列（LCS）。试炼的要求是：找出这个最长公共子序列的长度。</p><p>「LCS——双序列 DP 的经典之作，」李少白将两卷剑谱并排展开，「设 dp[i][j] 表示 A 的前 i 个字符与 B 的前 j 个字符的最长公共子序列长度。转移分两种情况。」</p><p>「若 A[i] == B[j]，则 dp[i][j] = dp[i-1][j-1] + 1，」赵晴儿执笔演算，「两字符相同，自然可以接在前面的公共子序列之后。若不同，则 dp[i][j] = max(dp[i-1][j], dp[i][j-1])——要么跳过 A 的这个字符，要么跳过 B 的这个字符。」</p><p>「O(N*M) 填完整个二维表，」梁嘉峰指着渐次被填满的矩阵，「dp[N][M] 便是答案。空间可优化至 O(min(N,M))——因为每行只依赖上一行和当前行的前缀。」</p><p>「两卷剑谱，一脉共序，」李少白收剑，「DP 表中每一个数字，都是武学传承的见证。」</p>

## 输入描述

<p>第一行包含两个整数N和M。</p><p>第二行包含一个长度为N的字符串，表示字符串A。</p><p>第三行包含一个长度为M的字符串，表示字符串B。</p><p>字符串均由小写字母构成。</p>

## 输出描述

<p><span style="color: rgb(51, 51, 51);">输出一个整数，表示最大长度。</span><br /></p>

## 样例

### 样例 1

#### 输入

```text
4 5
acbd
abedc
```

#### 输出

```text
3
```
