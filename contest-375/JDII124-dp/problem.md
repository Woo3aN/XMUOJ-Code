# JDII124 线性DP·最长共序

- 比赛：集训队试炼02 线性DP
- 题型：OI
- 难度：Mid
- 语言：C, C++, Java, Python3

## 题目描述

<p>九曲回廊的第二道弯，墙壁上刻着两串古文字。赵晴儿举着火把照过去：「这两卷剑谱——据说是同一位剑圣在不同时期写下的。一卷用甲骨文，一卷用金文。我想知道它们有多长的招式序列是完全一致的。」</p><p>李少白指着墙壁：「比如 acbd 和 abedc——它们最长的共同子序列是什么？」</p><p>他试着枚举：「从 acbd 中挑出 a、b、d，在 abedc 中也能按顺序找到——所以长度是 3。」</p><p>梁嘉峰摇头：「你肉眼能看出来，但程序不能。两串长度各可达一千——你得教它怎么找。」</p><p>赵晴儿在沙盘上画出一个网格，横轴是第二串，纵轴是第一串：</p><p>「dp[i][j] 表示第一串的前 i 个字符，与第二串的前 j 个字符，它们的最长公共子序列长度。如果两个串的最后一个字符相同——比如 a[i] == b[j]——那这个字符一定可以加入公共子序列， dp[i][j] = dp[i-1][j-1] + 1。」</p><p>「如果不同呢？」李少白追问。</p><p>「那就看丢掉第一串的最后一个字符（dp[i-1][j]），或者丢掉第二串的最后一个字符（dp[i][j-1]），取两者中较大的——反正这最后一个字符用不上。」赵晴儿说完，在纸上推了一遍 acbd 和 abedc，dp 表格一步步填满，最终右下角赫然写着 3。</p><p>「这就是<strong>最长公共子序列</strong>——LCS，线性 DP 的经典题。」梁嘉峰总结，「O(NM) 填完一张表，就可以读出任何位置的前缀答案。不仅用于字符串匹配，生物信息学里的基因序列比对也用同样的算法。」</p><p>给定两个字符串 A 和 B，求它们的最长公共子序列的长度。</p>

## 输入描述

<p>第一行包含两个整数N和M。</p><p>第二行包含一个长度为N的字符串，表示字符串A。</p><p>第三行包含一个长度为M的字符串，表示字符串B。</p><p>字符串均由小写字母构成。</p>

## 输出描述

<p><span style="color: rgb(51, 51, 51);">输出一个整数，表示最大长度。</span><br /></p>

## 样例

### 样例 1

#### 输入

```text
4 5
acbd
abedc
```

#### 输出

```text
3
```
