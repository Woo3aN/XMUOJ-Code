# JDII192 线性DP·飞笺传讯

- 比赛：集训队试炼01 DP基础入门
- 题型：OI
- 难度：Mid
- 语言：C, C++, Java, Python3

## 题目描述

<p>九曲回廊的第五道弯——飞笺传讯台。试炼场上坐满了弟子，排成 m 行 n 列的方阵。每个弟子心中都怀着一份「好心程度」——或温或凉，或厚或薄。</p><p>试炼规则：李少白坐在左上角 (1,1)，赵晴儿坐在右下角 (m,n)。少白要写一封灵笺传给晴儿，晴儿收到后再写一封回传给少白。灵笺每次只能向右或向下传递一格。更重要的是——两封灵笺的传递路线<strong>不能重叠</strong>（起点和终点除外），否则灵笺上的灵力会互相干扰，双双焚毁。</p><p>「两条路径，从 (1,1) 到 (m,n) 再回来——」梁嘉峰在沙盘上画出方阵，「其实等价于<strong>两个人同时从 (1,1) 出发走到 (m,n)</strong>，找两条不相交的路径，使经过的弟子好心程度之和最大。」</p><p>「这和上一关的方格双取如出一辙，」李少白点头，「设 dp[k][i1][i2] 表示两人各走了 k 步，第一个人在 i1 行、第二个人在 i2 行时的最大总好心值。列坐标由 k 和行坐标唯一确定。每步两人各有两个方向，共 2times2=4 种转移。若两人走到同一格，好心值只加一次。」</p><p>「O(N的三次方) 的三维 DP，N 小于等于 50 绰绰有余，」赵晴儿笑道，「关键洞察在于——两封灵笺一来一回，等价于两封灵笺同时从左上往右下传。方向统一了，状态才好设计。」</p><p>给定一个 m 行 n 列的矩阵，每个位置上有一个整数代表好心程度。求从 (1,1) 到 (m,n) 来回两条不相交路径（除起点终点）能收集的最大好心程度之和。</p>

## 输入描述

<p>第一行有 2 个用空格隔开的整数 m 和 n，表示弟子方阵有 m 行 n 列。</p><p>接下来的 m 行是一个 m 行 n 列的矩阵，矩阵中第 i 行第 j 列的整数表示坐在第 i 行第 j 列的弟子的好心程度，每行的 n 个整数之间用空格隔开。</p><p><strong>数据范围</strong> 1 小于等于 n, m 小于等于 50</p>

## 输出描述

<p>输出一个整数，表示来回两条路上参与传递灵笺的弟子的好心程度之和的最大值。</p>

## 样例

### 样例 1

#### 输入

```text
3 3
0 3 9
2 8 5
5 7 0

```

#### 输出

```text
34
```
