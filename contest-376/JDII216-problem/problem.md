# JDII216 树形背包·灵泽预算

- 比赛：集训队试炼03 背包DP专题
- 题型：OI
- 难度：Low
- 语言：C, C++, Java, Python3

## 题目描述

<p>灵泽商店中，金明小侠攥着 N 两银子的预算，面对琳琅满目的灵器——m 件物品分为主件与附件。规则严苛：必须先买主件，才能买其附属的附件（每个主件至多有两个附件）。每件物品有价格 v、重要度 p（1-5级），价值 = v * p。试炼要求：在预算内最大化总价值。</p><p>「分组背包的变体——依赖背包，」赵晴儿将主件和附件归类，「为每个主件枚举所有可能的购买组合——只买主件、主件+附件1、主件+附件2、主件+附件1+附件2。每种组合的总价格 = 各件价格之和，总价值 = 各件 (v*p) 之和。这些组合构成一个组——组内至多选一种。」</p><p>「对每个组做 01 背包倒序 DP，」李少白写出递推，「对于组 g 中的每种组合 (cost, value)：倒序容量 j，dp[j] = max(dp[j], dp[j - cost] + value)。组间的 dp 状态自然传递——前一组的结果作为后一组的起点。」</p><p>「N &lt;= 32000, m &lt;= 60——O(m * N) 的分组背包妥妥够用，」梁嘉峰核算完毕，「枚举组合时注意——可能存在主件无附件的情况，此时组内只有一种选择。」</p><p>金明小侠在分组背包的指点下挑好了灵器——主件与附件搭配有致，预算分文不超。</p>

## 输入描述

<p>输入文件的第 1 行，为两个正整数，用一个空格隔开：N,m，其中 N 表示总钱数，m 为希望购买物品的个数。</p><p>从第 2 行到第 m+1 行，第 j 行给出了编号为 j−1 的物品的基本数据，每行有 3 个非负整数 v,p,q，其中 v 表示该物品的价格，p 表示该物品的重要度（1~5），q 表示该物品是主件还是附件。</p><p>如果 q=0，表示该物品为主件，如果 q&gt;0，表示该物品为附件，q 是所属主件的编号。</p>

## 输出描述

<p>输出文件只有一个正整数，为不超过总钱数的物品的价格与重要度乘积的总和的最大值（&lt;200000）。</p><p><strong>数据范围</strong></p><p>N&lt;32000,m&lt;60,v&lt;10000</p>

## 样例

### 样例 1

#### 输入

```text
1000 5
800 2 0
400 5 1
300 5 1
400 3 0
500 2 0
```

#### 输出

```text
2200
```
